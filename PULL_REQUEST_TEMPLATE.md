**Commit convention:** The PR title is used as the merge commit message and determines the semantic-release version bump.

Format: `type(scope): description`

Examples:
- `feat(speaker): add GET /v1/voices endpoint`
- `fix(gateway): prevent websocket reconnection loop`
- `ci: add dependabot for Python dependencies`
- `docs: update architecture diagram`

Types: `feat` (minor), `fix` (patch), `perf`, `refactor`, `docs`, `test`, `ci`, `chore`, `BREAKING CHANGE` (major)
